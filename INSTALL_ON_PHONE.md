# Pocket Tilt Maze - Quick Install Guide for Android Phone

## 🎮 How to Get the Game on Your Phone

Since you have an Android phone, here's the **easiest way** to get your Pocket Tilt Maze game running:

### **Method 1: Use GitHub to Build APK** (Recommended)

1. **Create a GitHub account** (if you don't have one):
   - Go to: https://github.com/signup
   - Sign up for free

2. **Create a new repository**:
   - Click "New repository"
   - Name it: `pocket-tilt-maze`
   - Make it Public
   - Click "Create repository"

3. **Upload your project**:
   - Click "uploading an existing file"
   - Drag and drop ALL files from `c:\Users\Mahavir\Downloads\pocket tilt`
   - Click "Commit changes"

4. **GitHub will automatically build your APK**:
   - Go to "Actions" tab
   - Wait for the build to complete (5-10 minutes)
   - Download the APK from "Artifacts"

5. **Install on your phone**:
   - Transfer APK to your phone
   - Enable "Install from unknown sources" in Settings
   - Tap the APK to install
   - Play!

## 📲 Installing APK on Your Phone

Once you have the APK file:

1. **Transfer to phone** (USB cable, Google Drive, or email)
2. **Enable Unknown Sources**:
   - Settings → Security → Unknown Sources → Enable
   - Or: Settings → Apps → Special Access → Install Unknown Apps
3. **Tap the APK file** to install
4. **Open the app** and enjoy!
